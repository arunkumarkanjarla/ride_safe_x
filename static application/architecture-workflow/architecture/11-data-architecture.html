Scaling

Data rules

  • Partitioning: ride_locations by day, audit_logs and ride_events by month, dropped by the retention job.
  • Read replicas serve admin dashboards and reports so they never slow down bookings.
  • Money columns are numeric(12,2) with an explicit currency column; never floats.
  • Times are stored in UTC and shown in the city's time zone.
  • Soft delete for users (deletion requests anonymise personal fields but keep financial records required by law).
