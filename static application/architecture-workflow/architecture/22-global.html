Rules

Engineering rules for global

  • No country logic in code. Code reads the country pack; adding a country is configuration plus adapters.
  • Prices stored with currency, converted only for display when travelling.
  • Text never hard-coded. All strings go through translation keys, including notifications and invoices.
  • Right-to-left support is tested in every release for Arabic and Hebrew.
  • Personal data stays in the user's home region; operations in another country use that region with minimal data.
  • Where a global provider can't operate (for example map providers restricted in some countries), the region uses a local adapter.
