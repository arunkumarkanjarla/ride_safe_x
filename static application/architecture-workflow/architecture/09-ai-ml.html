Guardrails

Rules for AI decisions

  • The assistant can only call read tools for the signed-in user's own rides; writes go through tickets.
  • No model blocks an account, denies a refund, or files a report by itself. It raises a flag with reasons for a person.
  • Every prediction used in a decision is logged with model version and inputs for later review.
  • Personal data sent to an external LLM is minimised: ride IDs and status, never documents or card data.
