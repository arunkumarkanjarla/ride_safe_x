User needs & priority modes

Different people want different things: some are in a hurry, some have time, some want to save, some want coupons. The app ranks the same options differently for each.

Rules

Principles

  • Nothing is mandatory. Add-ons (insurance, luggage, pet, hotel, food stop) are never pre-ticked.
  • All options stay visible. Priority changes order and badges, it never hides a cheaper or faster option.
  • Badges are computed. Partners can't pay for "Best value" or "Cheapest".
  • Budget is soft. Options above the budget move down the list with a note; they don't disappear.
  • Accessibility and safety rules apply in every mode (wheelchair vehicles, women-only seats, verified riders).
  • Saved per trip type. A user can be Urgent in the city and Saver on long trips.
