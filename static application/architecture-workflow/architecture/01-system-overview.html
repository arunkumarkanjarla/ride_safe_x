What each layer does

LayerComponentsResponsibilityTechnology
ClientsRider app, driver app, admin portal, ops center, support softphoneEverything a person touches. Apps keep no business rules beyond validation and offline caching.Flutter, React + TypeScript, WebRTC
EdgeLoad balancer, API gateway, WebSocket gateway, call edgeSingle entry point, TLS termination, WAF, JWT validation, rate limits, routing, sticky WebSocket sessions.Nginx, Kong or Traefik, ModSecurity, Kamailio
Core services30 domain services: trip core, people, money, trust, travel, delivery and globalBusiness logic. Each service owns one PostgreSQL schema and publishes domain events.Python 3.12, FastAPI, Pydantic, SQLAlchemy, Alembic
AsyncKafka topics, Celery workers, schedulerEverything that can happen after the response: payments, notifications, invoices, analytics, AI scoring.Kafka, Celery, Redis Streams for small jobs
DataPostgreSQL, Redis, MinIO, OpenSearch, analytics DBDurable records, fast ephemeral state, files, search, reporting.PostgreSQL 16, Redis 7, MinIO, OpenSearch, ClickHouse
Provider adaptersMaps, payments, SMS/WhatsApp, push, KYC, LLM, SIP trunk, government APIsEvery outside provider sits behind an interface so it can be swapped per country.Adapter classes + config per region
Cross-cuttingSecurity, observability, DevOps, backup, complianceApplies to every layer.Keycloak, Vault, Prometheus, Grafana, Loki, OTel, GitHub Actions, K8s
