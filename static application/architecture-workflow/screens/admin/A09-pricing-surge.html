Surge is shown to riders before booking. Government fare caps for each city are enforced as hard limits.

How it works

  1. Fare rules are versioned; a change is a draft until a second manager approves it.
  2. The simulator shows the fare for a sample trip under old and new rules.
  3. Surge is recommended by the demand model and applied automatically within the cap, or set manually.
  4. Local fare caps set by regulators are hard limits the system never exceeds.

What is on the screen

  • Approval notice
  • Fare rule table with version
  • Edit, history, simulate
  • Demand vs supply chart
  • Surge zones with current multiplier, cap and mode

Edge cases and validation

  • During declared emergencies (floods, strikes) ops can freeze surge city-wide with one switch.
  • Every change is in the audit log with before and after values.
