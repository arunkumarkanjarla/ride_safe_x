How it works

  1. Search by name, phone, ride ID or email (OpenSearch index).
  2. Phone numbers are masked; opening the full record is logged.
  3. Row click opens the rider profile with rides, payments, tickets and risk history.
  4. Actions: warn, block, clear dues, reset devices — all need a reason.

What is on the screen

  • Status filters
  • Export
  • Rider table with risk and status
  • Pagination

Backend calls

MethodEndpoint / channelWhy
GET/v1/admin/riders?query=&status=&cursor=List
POST/v1/admin/riders/{id}/blockBlock with reason

Events published

admin.rider_blocked

Data used

  • users.riders
  • fraud.risk_scores
  • OpenSearch riders index

Edge cases and validation

  • Exports need report.export and only include masked fields unless approved.
  • Deleted accounts show as anonymised.
