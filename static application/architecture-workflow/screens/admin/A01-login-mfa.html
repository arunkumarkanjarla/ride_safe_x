How it works

  1. Staff enter email; the portal redirects to the identity provider (Keycloak or the company's SSO).
  2. Password is checked by the identity provider, never by the portal itself.
  3. A TOTP code or security key is required for every staff account.
  4. The portal receives an OIDC token with roles; the session lasts 8 hours with a 30-minute idle timeout.

Edge cases and validation

  • Login from a new country requires re-verification.
  • Accounts of people who left are disabled from the HR system automatically.
