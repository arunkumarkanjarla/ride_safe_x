How it works

  1. Camera opens with an edge guide; photos are checked for blur and glare on the phone.
  2. Files go straight to object storage with a signed URL; the API only stores the key.
  3. OCR reads number and expiry date; the driver confirms them.
  4. Submit sends the set to the KYC review queue.

What is on the screen

  • Step indicator
  • Document list with status and reason
  • Submit for review

Edge cases and validation

  • Rejected documents show the reviewer's reason.
  • Same licence already used by another account: sent to Fraud.
  • Document numbers are encrypted at rest.
