How it works

  1. Navigation uses the in-app SDK, or hands off to Google Maps / Waze if the driver prefers.
  2. Location is sent every 4 s so the rider sees the car move.
  3. 'Arrived' unlocks within 100 m of pickup.

What is on the screen

  • Next turn banner
  • Route to pickup
  • Rider name, ETA
  • Chat and call
  • Pickup note
  • Arrived slider

Edge cases and validation

  • Rider cancels: full-screen notice and cancellation fee credited if rules apply.
  • Driver far off the route: asked if they want to cancel instead.
