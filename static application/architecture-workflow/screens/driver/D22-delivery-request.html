How it works

  1. Dispatch times the offer so the partner arrives when food is ready, using the restaurant's prep estimate.
  2. Batching groups orders with drops in the same direction; the second drop adds at most 8 minutes.
  3. Earnings show distance pay, waiting pay and batch bonus.
  4. Accept locks the job like a ride offer.
