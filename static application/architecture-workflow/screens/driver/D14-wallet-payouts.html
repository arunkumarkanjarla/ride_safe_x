How it works

  1. Balance = settled earnings (100% of fares) − daily fees − GST on cash rides − adjustments.
  2. Automatic payouts run daily or weekly per city settings.
  3. Instant cash-out uses the gateway payouts API for a small fee.
  4. Bank account changes need OTP and a 24-hour cool-down to stop account takeover fraud.

What is on the screen

  • Available balance
  • Next payout
  • Cash out
  • Bank account
  • Daily fees
  • Payout history with status

Edge cases and validation

  • Negative balance (unpaid daily fees): taken from the next earnings, no interest; after 3 unpaid days the driver is asked to pay before going online.
  • Payout failed: reason and automatic retry.
