How it works

  1. Offer arrives with a loud sound and vibration, even in the background.
  2. The countdown matches the server's offer timeout.
  3. Accept is checked on the server against the driver lock; the first valid accept wins.
  4. Decline or timeout passes the ride to the next driver.

What is on the screen

  • Countdown
  • Fare and estimated earning
  • Surge
  • Pickup distance and time
  • Drop distance
  • Rider rating
  • Decline and accept

Edge cases and validation

  • Accepted too late: 'Ride taken by another driver'.
  • Many declines in a row lower priority for a short time, never block the driver.
  • Drop address is shown in full so drivers can decide fairly (required in several markets).
