How it works

  1. Each step updates when the KYC or operations team decides.
  2. Training can be done while waiting; a short quiz confirms it.
  3. When all steps pass, the driver status becomes ACTIVE and home unlocks.

What is on the screen

  • Expected time
  • Step timeline with state
  • Training shortcut
  • Support link

Edge cases and validation

  • A step rejected: jumps back to the related upload with the reason.
  • Background check result is never shown in detail, only pass or contact support.
