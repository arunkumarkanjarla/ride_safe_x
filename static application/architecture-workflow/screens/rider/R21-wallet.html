How it works

  1. Balance comes from the ledger, never from a number stored on the phone.
  2. Add money opens the gateway checkout; balance updates when the webhook confirms.
  3. Wallet is used first when a ride is paid, the rest from the default method.

What is on the screen

  • Balance card
  • Add money
  • Payment methods with default
  • Recent wallet transactions

Edge cases and validation

  • Card data never touches the platform's servers; only gateway tokens are stored.
  • Wallet limits per local regulation (for example a monthly cap without full KYC).
