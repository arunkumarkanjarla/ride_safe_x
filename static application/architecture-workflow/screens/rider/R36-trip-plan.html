How it works

  1. The planner joins legs from different services: city ride, bus, rental, hotel.
  2. Transfer buffers are added automatically (15–30 min) based on reliability data.
  3. Optional items stay optional; the total changes only when the user adds them.
  4. No-network stretches are shown as a dashed leg with expected duration.

What is on the screen

  • Plan summary: total and door-to-door time
  • Leg timeline with times and prices
  • Optional stops and add-ons
  • No-network leg
  • Customise and book all

Backend calls

MethodEndpoint / channelWhy

Events published

plan.created plan.booked

Data used

  • planner.plans, planner.legs

Edge cases and validation

  • One leg fails to book: others are held, the user can pick a replacement or cancel all with full refund.
  • Bus delay over 30 min re-plans the next legs and notifies the rental partner.
