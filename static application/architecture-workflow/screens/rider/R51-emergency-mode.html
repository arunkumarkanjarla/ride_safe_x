Emergency mode

A calm, fast path in a medical emergency: call for help, find the nearest emergency department, and get a ride without surge.

Priority dispatch. Surge and add-ons are switched off in emergency mode.

How it works

  1. Emergency numbers come from the country pack (112, 108, 911, 999 and others).
  2. Hospital list comes from map data filtered to emergency departments, with live travel time.
  3. The ride is dispatched with top priority, no surge and no upsell.
  4. This mode never replaces an ambulance; the call buttons are first.

What is on the screen

  • Call emergency and ambulance
  • Country note
  • Nearest emergency hospitals
  • No-surge priority ride
  • Share location

Edge cases and validation

  • Abuse of emergency mode is reviewed, but never blocks a ride at the time.
