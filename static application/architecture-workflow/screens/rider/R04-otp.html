How it works

  1. Android reads the SMS automatically (SMS Retriever API); iOS offers one-tap autofill.
  2. Verify sends phone, code and device ID.
  3. Auth returns a 15-minute access token and a 30-day refresh token, stored in secure storage.
  4. New users go to profile setup, returning users to home.

What is on the screen

  • Six code boxes
  • Edit number link
  • Resend timer and WhatsApp option
  • Verify button

Data used

  • identity.users, identity.devices

Edge cases and validation

  • Wrong code: shake animation, attempts left shown; 5 wrong tries lock for 30 minutes.
  • Code expired: prompt to resend.
  • New device for an existing account: extra risk check before tokens are issued.
