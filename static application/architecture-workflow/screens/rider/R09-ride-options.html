How it works

  1. App requests quotes for all vehicle types in one call.
  2. Pricing returns fares with a quote ID valid for 5 minutes; surge is shown openly.
  3. Tapping a type updates the button; long-press shows the fare breakdown.
  4. Book goes to pickup confirmation.

What is on the screen

  • Route preview on map
  • Vehicle list with ETA, seats, fare
  • Surge notice
  • Payment method and coupon
  • Book button

Edge cases and validation

  • Quote expired: refresh prices silently and highlight any change.
  • No drivers for a type: shown greyed with 'none nearby'.
  • Surge above 1.5×: ask for explicit confirmation.
