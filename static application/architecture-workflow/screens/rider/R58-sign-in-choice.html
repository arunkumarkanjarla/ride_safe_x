How it works

  1. Create an account and I already have an account both continue to phone verification (R03); the mode only changes the wording.
  2. Demo accounts fill in a synthetic phone number so reviewers can try both the returning and the new-customer path.
  3. The Terms and Privacy link opens the summary (R57).

What is on the screen

  • Brand header
  • Create an account
  • I already have an account
  • Demo account list
  • Terms and privacy link

Backend calls

None; this screen works from local state.

Events published

None

Data used

  • Nothing is stored; the demo state lives in memory only

Edge cases and validation

  • The prototype never creates a real account.
  • Reloading the page signs everyone out (in-memory demo).
