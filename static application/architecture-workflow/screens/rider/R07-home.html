How it works

  1. Gets the current location and reverse-geocodes it as the default pickup.
  2. Polls nearby cars every 10 s (approximate positions only, no driver identities).
  3. Where to? opens search; saved places and vehicle tiles jump straight to options.
  4. Offers banner shows the best applicable coupon.

What is on the screen

  • Map with blue location dot and nearby cars
  • Greeting, menu, notifications
  • Where to? with Now / Schedule
  • Saved places
  • Vehicle type shortcuts
  • Offer banner
  • Bottom navigation

Backend calls

Events published

None

Data used

  • Location (while using the app)
  • Saved places

Edge cases and validation

  • Outside a service area: banner 'Not available here yet' and waitlist.
  • Active ride exists: home is replaced by that ride's screen.
  • Car positions are jittered so real driver locations are not exposed.
