Customer app · R05

Profile setup

Collects the few details needed to book: name, optional email, optional gender for safety preferences.

How it works

  1. Name is required; email is optional and verified by a link.
  2. Gender is optional and only used for features like preferring women drivers.
  3. Referral code is validated and credit added after the first ride.

What is on the screen

  • Photo picker
  • Name, email fields
  • Optional gender chips
  • Referral code
  • Continue

Edge cases and validation

  • Name with emoji or digits only: validation error.
  • Invalid referral: soft warning, can continue.
  • Photo is compressed to under 300 KB before upload.
