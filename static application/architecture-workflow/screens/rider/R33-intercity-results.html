How it works

  1. Results stream in as each supplier answers; slow suppliers don't block the list.
  2. Price bands (₹, ₹₹, ₹₹₹) are calculated per route from the spread of prices.
  3. The network-coverage check runs on the route and shows a warning if there are no-signal stretches.
  4. Selecting an option opens its detail: seats, boarding points, driver or rental terms.

What is on the screen

  • Route summary
  • Type filters
  • Price band filter
  • Sort label
  • Option cards with times and badges
  • No-network warning

Data used

Edge cases and validation

  • Prices from partners are re-checked at booking; a change is shown before payment.
  • Night travel through restricted roads is flagged with the restriction hours.
