How it works

  1. The service grid comes from the country pack, so each country shows only what is live there.
  2. The priority chips (Urgent, Balanced, Saver, Flexible, Deals) set how every result list is ranked; nothing is forced, the user still sees all options.
  3. Search understands places and needs: 'Mysuru', 'biryani', 'hotel near bus stand', 'send documents to Kochi'.
  4. Upcoming trips and savings are pulled from bookings and the ledger.

What is on the screen

  • Pickup location and country/currency
  • Search with voice
  • Priority chips
  • Service grid with badges
  • Upcoming trip card
  • Monthly savings meter
  • Bottom navigation

Edge cases and validation

  • A service not available in the country is hidden, not greyed out.
  • First-time users see Balanced selected and a one-line explanation of the chips.
  • In an area with no network the home shows cached services and the offline pack.
