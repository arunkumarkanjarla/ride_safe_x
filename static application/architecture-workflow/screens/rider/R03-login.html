How it works

  1. Country code defaults from the SIM or locale; the rider can change it.
  2. Number is validated with libphonenumber before sending.
  3. Send OTP calls the auth service, which rate-limits per phone and device.
  4. On success the app moves to OTP entry.

What is on the screen

  • Country code picker
  • Phone number field with numeric keypad
  • Terms and privacy consent line
  • Send OTP button
  • Google and Apple sign-in

Backend calls

Data used

  • Device ID
  • Phone number

Edge cases and validation

  • More than 3 requests in 10 minutes: show a wait timer.
  • Invalid number: inline error, button disabled.
  • Number blocked by Fraud: generic message, link to support.
  • Google/Apple sign-in still asks for a phone number once (needed for drivers to reach you).
