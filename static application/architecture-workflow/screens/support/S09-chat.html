How it works

  1. Start puts the person in a queue; a simulated agent joins.
  2. Messages get keyword-based replies with a typing indicator.
  3. End chat asks for confirmation; Turn into a ticket keeps the transcript.
  4. When no agent is available the chat offers a ticket instead.

What is on the screen

  • Queue / agent status
  • Messages with timestamps
  • Typing indicator
  • Composer
  • End chat
  • Escalate to ticket

  • Messages over 500 characters are refused.
