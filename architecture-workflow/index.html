RideNova · rides, travel, food & parcels

One app for any country: city rides, long trips of 200–500 km and more, shared seats, buses, rentals, hotels, restaurants, food delivery and parcels. Every user chooses what matters to them (speed, saving, time or deals), every add-on is optional, and the app plans ahead for areas with no mobile network.

Using this package

How to use these files

  • Open index.html in any browser. Everything works offline; there are no external fonts or scripts.
  • To rename the product, edit assets/brand.js and change BRAND_NAME. All pages update. The PNG pictures keep the old name until you re-render them with the scripts in source/.
  • All pictures are in images/: diagrams as SVG, screens as PNG. The image gallery shows them all.
  • Prices, distances, coverage data and road rules in the mockups are examples for planning, not real data.
  • The source/ folder has the Python scripts that generated this package, if you want to change content and rebuild.
