## 6. Image review method

* 6 PNGs were opened and inspected visually (R07, R12, D07, P02, A04 and the reference architecture image); they match
  the corresponding HTML mocks exactly in layout, data and copy.
* All 118 screen PNGs are produced by `shots.py` from `#mock > *` of the matching spec page, so the mapping
  screen ↔ PNG is deterministic (file name = screen ID). See [screen-image-mapping.md](screen-image-mapping.md).
* PNG timestamps: 111 rendered 8 Oct 05:24, 7 re-rendered 9 Oct 08:25 (A29, D01, D11, D13, D14 and others). Generator
  modules `driver.py`, `screens2.py`, `screens3.py` were edited on 9 Oct, so a few PNGs may lag the HTML; the HTML is the
  source of truth and the prototype is built from it.
* All 40 SVG diagrams were read as text (labels extracted) to recover state machines, sequences and rules
  ([architecture-findings.md](architecture-findings.md)).
