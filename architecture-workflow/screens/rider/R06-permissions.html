Permissions

A few permissions
We ask only for what the app needs. You can change these any time in Settings.
LocationRequired to find drivers near you
NotificationsDriver arrival, trip and safety alerts
ContactsOptional, to pick emergency contacts
MicrophoneOnly for in-app calls
Location is shared with your driver only during a trip.

How it works

  1. Each toggle triggers the operating system permission dialog.
  2. Location 'while using the app' is enough; background location is not requested for riders.
  3. The choices are stored so the app doesn't ask again.

What is on the screen

  • Privacy note

Edge cases and validation

  • Location denied: home shows a manual pickup search instead of the blue dot.
  • Notifications denied: in-app banners replace pushes.
  • Precise location off (iOS): ask once to enable for accurate pickup.
