How it works

  1. Menu and stock come from the restaurant's live menu (P03).
  2. Delivery speed options reflect the priority modes; Saver uses batching.
  3. The best eligible coupon is applied automatically; the user can switch to another.
  4. Payment confirms the order to the restaurant.

What is on the screen

  • Restaurant header
  • Menu items with veg / non-veg mark and quantity
  • Delivery speed options
  • Auto-applied coupon
  • Pay button
