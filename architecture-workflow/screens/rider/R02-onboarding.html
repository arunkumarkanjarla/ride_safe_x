How it works

  1. Rider swipes through three slides: safety, fair prices, many vehicle types.
  2. Language picker stores the choice locally and on the profile later.
  3. Get started opens phone login.

What is on the screen

  • Language selector
  • Illustration
  • Headline and one-line explanation
  • Page dots
  • Get started button
  • Link to the driver app

Backend calls

None; this screen works from local state.

Events published

None

Data used

  • Local flag: onboarding_seen
  • Chosen language

Edge cases and validation

  • Right-to-left languages mirror the layout.
  • Skipped automatically after the first run.
