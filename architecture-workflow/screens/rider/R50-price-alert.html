How it works

  1. Price history per route and time builds the weekly pattern.
  2. The watcher checks new seats and bus fares every 15 minutes.
  3. Auto-book uses the saved payment method within the user's limits and sends a receipt.
  4. The alert ends after booking or when the window passes.

Edge cases and validation

  • Auto-book never exceeds the set price or the budget.
  • If nothing matches by the deadline, the user gets the best available options.
