Travelling abroad? The app switches automatically when you land and keeps your account and wallet.

How it works

  1. Country is detected from location and SIM; the user can override it.
  2. Each country loads a country pack: services, currency, payment methods, emergency numbers, laws.
  3. Language changes the whole app, including right-to-left scripts such as Arabic.
  4. Wallet balances are kept per currency.

What is on the screen

  • Country list with services, currency and emergency number
  • Language chips in native scripts
  • Units
  • Travel note

Edge cases and validation

  • Personal data stays in the home region; trips abroad use the local region for operations only.
  • Missing translations fall back to English, never to blank text.
