How it works

  1. Holding the button for 2 s prevents accidental alerts.
  2. Safety service opens a P1 incident and raises an alarm on the ops console.
  3. Emergency contacts get an SMS/WhatsApp with a live trip link.
  4. A safety agent calls within 60 seconds; the emergency number button dials directly from the phone.

What is on the screen

  • Hold-to-send SOS
  • Status of the alert
  • Contacts notified
  • Safety agent status
  • Call emergency number
  • Recording notice

Edge cases and validation

  • Works without internet: sends an SMS with location as a fallback.
  • Emergency number is localised per country (112, 911, 999).
  • The app never says police were contacted unless an agent confirms it.
