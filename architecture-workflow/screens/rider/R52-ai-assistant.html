How it works

  1. The assistant turns the request into a structured search: route, date, party, budget, priority, wishes.
  2. It calls the same planner, search and coverage tools the app uses, so prices are real.
  3. Nothing is booked until the user taps a confirm button.
  4. Voice input works in local languages.

What is on the screen

  • User request
  • Plan card with legs and prices
  • Coverage heads-up
  • Quick follow-ups
  • Voice / text input
