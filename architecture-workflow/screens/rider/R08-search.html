How it works

  1. Typing calls autocomplete through the Maps adapter, biased to the rider's location, with 250 ms debounce.
  2. Choosing a place gets its coordinates (place details).
  3. Pickup can be changed the same way.
  4. When both are set, the app asks for fares.

What is on the screen

  • Pickup and drop fields
  • Suggestions with distance
  • Set on map
  • Recent places
  • Add stop (up to 2)

Backend calls

MethodEndpoint / channelWhy
GET/v1/places/autocomplete?q=Suggestions via Maps adapter
GET/v1/places/{id}Coordinates for a place

Events published

None

Data used

  • Recent searches (on device)
  • Session token for billing-efficient autocomplete

Edge cases and validation

  • Destination outside the service area: explain and offer outstation rental.
  • Same pickup and drop: blocked.
  • Airport destination: asks for terminal.
