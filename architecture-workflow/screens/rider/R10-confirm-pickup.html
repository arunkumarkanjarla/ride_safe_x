How it works

  1. Map is movable; the pin stays centred and the address updates on stop.
  2. Suggested pickup points (gates, entrances) snap the pin.
  3. Confirm creates the ride with an idempotency key so a double tap never books twice.

What is on the screen

  • Draggable map under a fixed pin
  • Pickup address
  • Payment methods
  • Confirm button

Edge cases and validation

  • Pin moved over 300 m: re-quote the fare.
  • Payment method needs re-authentication (UPI mandate): open the gateway sheet first.
  • Rider has unpaid dues: must settle before booking.
