How it works

  1. City decides local rules: which documents, which vehicle types, which fees.
  2. Fleet drivers are linked to a fleet owner who manages the vehicle.
  3. Progress is saved, so the driver can come back later.

What is on the screen

  • Step indicator
  • Name, city
  • Vehicle type
  • Ownership
  • Languages (for rider matching and chat)
  • Referral code
  • Next
