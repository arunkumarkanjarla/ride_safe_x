Driver login

Login and sign-up entry for drivers, using the same OTP flow as riders but a separate driver role.

How it works

  1. Phone number and OTP work as in the rider app.
  2. A number can be both a rider and a driver; the role in the token decides which APIs are allowed.
  3. New drivers go to registration, existing drivers to home.

What is on the screen

  • Earnings pitch
  • Country code and phone
  • Send OTP
  • Fleet invite hint
  • Numeric keypad

Backend calls

MethodEndpoint / channelWhy
POST/v1/auth/otpSend OTP
POST/v1/auth/verify?role=driverVerify and issue driver token

Events published

user.logged_in

Data used

  • identity.users
  • identity.devices

Edge cases and validation

  • One active driver session per phone; logging in elsewhere logs out the old device.
  • Device must pass integrity checks (Play Integrity / App Attest) to go online.
