How it works

  1. Location every 3 s; points are buffered on the phone if the network drops.
  2. Stops and destination changes by the rider appear as a banner.
  3. End trip sends the final GPS trail; the server computes the fare.

What is on the screen

  • Next turn
  • Route to drop
  • Rider and ETA
  • SOS
  • Running fare
  • End trip slider
