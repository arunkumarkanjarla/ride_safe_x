How it works

  1. Zones are polygons stored with PostGIS and cached by the location service.
  2. Each zone has a type, rules and an optional schedule.
  3. Changes are validated (no gaps in the service area, no self-crossing shapes) and take effect within a minute.

What is on the screen

  • Map with zones
  • Zone list with type and rule
  • Draw and import tools

Edge cases and validation

  • Deleting a zone with active surge first sets it to 1.0×.
  • Temporary zones (events, road closures) expire automatically.
