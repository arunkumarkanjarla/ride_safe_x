How it works

  1. Call records come from Asterisk CDRs via the telephony service.
  2. Recordings are played in the browser with a signed URL; each play is audited.
  3. Health tiles read Asterisk and Kamailio metrics from Prometheus.

What is on the screen

  • Call KPIs
  • Call log with proxy, duration, result, recording
  • Voice health: trunks, PBX nodes, WebRTC gateway, proxy pool usage
