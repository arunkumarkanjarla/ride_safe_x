# Story 9.2 — Payment APIs & customer sandbox UI

Status: Ready for Review · Phase 9

## APIs
- POST /payments (idempotent)
- GET /payments/{id}, GET /payments?booking_id=
- POST /payments/{id}/sandbox/simulate (non-production only)
- POST /payments/sandbox/callback (token-authenticated, non-production)

## UI
Customer active/history booking: sandbox pay section; no card/UPI fields.
