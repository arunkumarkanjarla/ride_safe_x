# Story 2.3 — RBAC and object-level authorization

Status: Approved  
Phase: 2

## Goal

Server-enforced permissions; profile self-access; privileged user/role/audit endpoints; reject IDOR and self-elevation.

## Acceptance

- Missing permission → 403; unauthenticated → 401
- User A cannot read User B private profile by ID swap
- No public self-grant of admin roles
