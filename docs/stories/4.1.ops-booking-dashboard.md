# Story 4.1 — Operations booking dashboard

Status: Done · Phase 4

## Goal
Server-paginated ops booking list, status summary counts, filters, and booking detail (fare, coords, events, assignment) in the web portal.

## Acceptance
- `GET /ops/bookings` and `GET /ops/bookings/summary` require `bookings.read`
- Pagination never returns unbounded sets
- Detail includes persisted offers/events; no fabricated fields
- Portal shows loading/empty/error/forbidden states
